# 拾影：照片分類 sample

無需安裝套件的 GitHub Pages 靜態網頁。每次選一張照片，填寫必填說明，選擇固定三層分類後儲存。支援預覽、拖曳選圖、收藏列表與單筆刪除。

分類在 `app.js` 的 `CATEGORIES` 設定：A/B/C → A1/A2/A3 → A1-1/A1-2/A1-3，以此類推。

照片以 Blob 儲存在目前瀏覽器的 IndexedDB，不會上傳 GitHub 或任何伺服器。重新整理仍保留，但不同裝置或瀏覽器不共用；清除網站資料會刪除紀錄。正式多人收件需要另外串接後端與檔案儲存。

本機可直接開啟 index.html，或執行 `python3 -m http.server 8000`。
